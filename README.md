Welcome to the PebbleNavMe repository! 
Here you'll find releases that I've made for PebbleNavMe under the releases tab, and also the source code that I'm working from. Because I'm not the original author, I haven't got access to the original source code so everything here is in smali which is what I've been making my edits in.

For people who are just here for a working version of the APK, head to releases. There you'll fall into one of two categories:
-For users using a Google Maps version **newer** than December 2025 and **using** Live Alerts, use the latest version.
-For users using a Google Maps version **older** than December 2025 **or** using a version newer than December 2025 but with Live Alerts turned **off**, use v1.56

Thanks and hopefully the app is useful to folks :)
